## Question
PR #159 measured on recorded activations that a per-head decay table keyed on x (U4) keeps every head's decay within half a BF16 ulp per token and 0.01 accumulated, while the best table chain (U3) misses the per-token bar on 815 of 23,040 cells. Neither was run inside the model. With U4's or U3's decay in place of XS18's float decay in all 48 DeltaNet layers, does the abliterated model keep PR #124's token-agreement bar on the same 10 prompts?

## Hypothesis
H (falsifiable): XS18+U4 meets the acceptance threshold below on the abliterated leg (all 1,461 positions), and adds no top-1 flip, relative to XS18, at a position whose REF top-1 margin exceeds 0.01 logits.
XS18+U3 gets its own PASS / FAIL with no directional hypothesis (issue #170: a U3 pass says the per-head bar of PR #146 / #159 is stricter than the end-to-end outcome needs; a fail says it is not). Any combination of verdicts is a valid outcome and is reported as measured.

## Setup (fixed now)
- Harness: PR #124's `e2e.py` design, abliterated leg only: stock layers 0 to 16 (byte-identical in both checkpoints, PR #68), then abliterated layers 17 to 63, abliterated final norm and lm_head. Checkpoints, revisions, weight fetch by HTTP range request one layer at a time with sha256 of every tensor, float64 forward, streaming lm_head metrics: PR #88 `q1_forward.py` and PR #124 `e2e.py` functions, imported unchanged. The new runner (`decay_e2e.py`, this directory) reuses `e2e.py`'s `layer_all`-style loop, `Stream`, `logits_metrics`, `lm_head_chunks`, `save_state` / `load_state`; it only adds paths. No stock leg (issue: out of scope).
- Prompt set: PR #124's frozen `prompts-e2e.json` (sha256 47aa61b46e142382ffa58b88f918df6ec63f1158629df5938ec00961a5242cfc), all 10 prompts, 1,461 positions, teacher forced. Nothing is re-chosen.
- Paths (each closed loop through all 64 layers, its own residual stream):
  - **REF**: float64 throughout (PR #124's REF).
  - **XS18** (control): every DeltaNet layer's heads by `scaled_head.Head` with PR #88's arm `XS18` from `arms-q1.json`, unchanged. Must reproduce PR #124's committed abliterated numbers (see "Control").
  - **XS18+U4**: XS18 with the decay value a replaced, per token and V head, by PR #159's arm U4 (`decay_r2.arm_decay(ar, A, dt_bias, "U4", tables)`, imported unchanged), converted to XS18's gate scale.
  - **XS18+U3**: the same with PR #159's arm U3 (same call with "U3"; tables from `decay_r2.load_tables`, the 2^20-row fine exp table generated by `decay_r2.py fine20` with the pinned integer generator, sha256 recorded).
  - Determinism (instead of repeats): REF#2 and XS18+U4#2 on p01-ordinary-short and p09-multilingual.
- In every integer path, in_proj, out_proj, full attention, MLP, every RMSNorm, the final norm and lm_head stay float64, as PR #124. Only the DeltaNet head computation is lowered; in the U paths only the decay a differs from XS18. beta, the recurrence, the state scale 2^18 and everything downstream are XS18's.
- **Decay input (registered).** The U arms take the path's own float64 head input ar (the output of in_proj_a on that path's own residual, per token and V head), with the layer's A = exp(A_log) and dt_bias, exactly the inputs PR #159 evaluated U3 / U4 on (PR #146's recorded ar). They do not take XS18's quantised ar (2^14); that quantisation only feeds XS18's own float decay. PR #159's front end (floor(2^12 ar) + RNE(2^12 dt_bias), row floor(X / 16)) is applied inside the imported function.
- **Registered conversion, a deviation from the arms as measured in PR #159.** PR #159's U3 and U4 output a as an integer a20 at scale 2^20. XS18 holds a as an integer at its gate scale 2^Fg = 2^18. The conversion is one right shift by 2 with round half up: a18 = floor((a20 + 2) / 4), computed in Python / int64 integers. This rule matches XS18's registered rounding mode (rnd = rhu) and is the only change to the PR #159 output. It adds at most 2^-19 = 1.9e-6 of absolute error per token on top of PR #159's measured e_tok (max 0.000712 for U4), so the arm run here is "U4 (or U3) at 2^-18", not the arm PR #159 measured at 2^-20. XS18's own `np.rint` on a is then a no-op (a18 is an integer).
- **Guard errors.** An OverflowError in `scaled_head` (as PR #124), or any lookup that PR #159's arm would reject (U4: a key at or above its domain end, x >= 32; `arm_decay` returns the reject mask), is a guard error for that path on that prompt: every position of the prompt counts as disagreeing with KL = infinity, and the path is dropped for that prompt from then on. U3 clamps and never rejects (PR #159). Below U4's domain (x < -16) the key is clamped, as PR #159; this is not a reject.
- **How the decay is substituted.** `scaled_head.py` is imported unchanged. The runner builds a subclass of `Head` whose `run` is `Head.run`'s own source with exactly one line replaced (the `a = ...` line above, replaced by a call that returns either XS18's own float value, for the control, or the converted table value); the replacement is asserted to match exactly once. Debug checks below confirm that the control variant is bit-identical to `Head.run`.
- CPU only. No GPU, no serving route, no spend.

## Metric
Per path P in {XS18, XS18+U4, XS18+U3}, per position, against REF, exactly PR #124's metrics: top-1 agreement (ties to the lowest id), KL(REF || P) in nats over the full vocabulary (streaming lm_head, float64), max |z_REF - z_P| / REF logit SD, REF's top-1 margin. Over the 1,461 positions: top-1 agreement count, KL median, p99, max, SD; per prompt: top-1 count, KL median and max; every top-1 flip with prompt, position, REF margin and KL; p03-repeat-word reported on its own line. Per layer: wall seconds and residual relative difference per path and prompt. Run: peak RSS (`time -v`), wall time.
Descriptive, no threshold: per DeltaNet layer and path, max over tokens, heads and prompts of |a_P / 2^18 - a_float| (the decay error the path actually used, against float64 decay of the same path's ar); closed-loop per-head rel_y of each integer path vs float64 heads on that path's own head inputs (as PR #124).

## Acceptance threshold
PR #124's bar, unchanged, per arm on the abliterated leg: over the 1,461 positions, with no guard error on any prompt,
1. top-1 agreement >= 99.0% (at most 14 disagreements), and
2. KL(REF || arm) median <= 1e-4 nats, and
3. KL max <= 0.1 nats.
H holds iff XS18+U4 passes and has no top-1 flip that XS18 does not have at a position with REF margin > 0.01 logits. XS18+U3: PASS / FAIL against the same bar; its extra flips at margin > 0.01 are reported.
**Control.** XS18 reproduces PR #124 iff its per-position top-1 list equals PR #124's committed abl XS18 list (`runs/e2e-abl.json`) at all 1,461 positions, REF's top-1 list equals PR #124's REF list, and every per-position KL differs from PR #124's by at most 1e-9 nats. If the control does not reproduce, the U arms' numbers are reported but their verdicts are KILLED (the harness is not the one PR #124 measured), and the difference is reported.

## Runs
The forward is deterministic float64 and integer arithmetic; there are no seeds. Five or more repeated runs of a deterministic forward would give identical numbers, so none are made; the spread reported is over the 1,461 positions and the 10 per-prompt values. Determinism check instead: REF#2 and XS18+U4#2 on p01 and p09 must be bit-identical to REF and XS18+U4 after every layer and in every logit metric.
- One run, through the heavy-CPU gate (`fp-heavy.sh` and the shared big-memory lock), pinned to 6 cores, BLAS threads 6 for the dense steps (one call per path and prompt, as PR #124, so duplicate paths see identical shapes), head recurrences in a pool of 6 spawned workers with 1 BLAS thread. Host shared and loaded; recorded in ENV.json. The core set differs from PR #124's; the control check above covers that.
- No exclusions. Every prompt and position counts.
- Debug before the registered run, disclosed now: only on the fixture "The capital of Italy is" (PR #88's FIXTURE, not a suite prompt), stock layers 0 to 3, all paths: (a) the one-line-substituted `run` with the control decay is bit-identical to `Head.run`; (b) U4 / U3 decay values inside the head equal `floor((decay_r2.arm_decay(...) * 2^20 + 2) / 4)`; (c) save / load and resume equality; plus synthetic logits for the streaming metrics as PR #124. ## Prior art
In this repo: PR #124 (end-to-end harness and bar; XS18 abl 1,460 / 1,461 top-1, KL median 2.95e-6, max 0.00566, measured, unreplicated), PR #146 (four table designs T0 to T3 fail the per-head decay bar), PR #159 (round-2 designs: U4 passes, U3 fails 815 of 23,040 cells on the per-token bar, all on tokens with g >= 1), PR #88 (per-head bar vs end to end), PR #68 (layers 0 to 16 byte-identical). Outside: lookup-table evaluation of non-linear functions in zero-knowledge ML (zkLLM's tlookup, Sun et al. 2024; EZKL and Jolt lookup arguments) fixes a table and checks membership, and quantisation work (LLM.int8(), SmoothQuant, GPTQ, AWQ) reports whole-model fidelity against the full-precision model, often as perplexity and sometimes as KL or argmax agreement. Gated DeltaNet (Yang et al. 2024) and Mamba-style state-space models compute the decay in floating point; we know of no published end-to-end measurement of a table-based decay inside a hybrid linear-attention LLM. New here: the token-level effect of PR #159's table decays in all 48 DeltaNet layers of Qwen3.8-27B abliterated, under the same harness and bar as PR #124.
