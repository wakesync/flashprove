# Pre-registration smoke test (NOT a result)

`smoke.jsonl` and `smoke.summary.json` are the rows of the 2-prompt smoke test that PREREG amendment A-2 discloses: the
candidate code path of the first engine version, run on prompts p01 and p09 (34 of the 2,396 tokens, 96 of the 480
pairs), outside the heavy gate, while step 1 attempt 1 was still queued. They are committed unchanged (copied from the
lane's working files) by amendment A-4, because A-2 quotes numbers from them and the repo's evidence rule needs the
rows in the repo.

They are not results. They ran before step 1 was settled, on an engine version that was changed afterwards (A-2), and
on 96 pairs. Nothing in RESULTS, the ledger or the README is computed from them. They record what the author had seen
before amendment A-3 moved the stop rule and before X1 to X3 were defined.
