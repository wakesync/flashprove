## Metric
Per run (one run = one seed of fixtures and prover coins) and per named case: the verifier's accept/reject bit, whether the case is a complete proof, and, for hostile witnesses, the number of violated relations (must be > 0, else harness bug). Counts per case over runs. Digests: hex configuration digest of v1 and v2 per profile, and of v2 with a changed table or changed claimed manifest hash; per-table SHA-256 printed by the C++ harness, compared by Python against `tables/manifest.json` and `tables/rotary-manifest.json`. Accounting: per profile, every plan round (name, where, count, work bits, minus log2 of its whole error), `account().sum` and the round count, printed through `blocks/numbers/accounting.h`. Run records: presence and ISO-8601 UTC format of `started_utc` / `finished_utc`.
