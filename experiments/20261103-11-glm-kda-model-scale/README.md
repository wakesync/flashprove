# 20261103-11-glm-kda-model-scale (pre-standards, exploratory)

Env manifest location for the GLM KDA head-slice model-scale sweep (PR #42, issue #11), placed
here per `loop/STANDARDS.md`. The code, raw data and write-up stay where the lane produced them:

- write-up: `research/model-scale/RESULTS.md`
- raw data: `research/model-scale/results/`
- env manifest: `ENV.json` (this directory)

There is **no PREREG.md**, on purpose. The lane started before the research standards existed, and
a PREREG written afterwards would be backdated. The branch is recorded as standards-exempt, and
every number is labelled "measured, unreplicated". Nothing here passes or fails a pre-registered
threshold. Any follow-up that wants a headline number has to register a new `<id>` with a
PREREG first, and an independent lane has to replicate it.
